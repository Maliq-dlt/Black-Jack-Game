## 2024-03-24 - [Avoid synchronous localStorage on component mount]
**Learning:** The `App.tsx` file defines `loadMeta`, `loadSettings`, and `loadStats` outside the component to avoid recreating the functions on every render. However, until this fix, `App.tsx` still performed a synchronous `localStorage.getItem` directly when declaring `const initialMeta = loadMeta();` and setting the initial values of `useState` with `useState(loadStats)` outside of lazy initializer callbacks. This meant that any re-render of `<App />` could still potentially trigger the read logic (though React typically ignores it after mount), or it was run eagerly before `useState`.
**Action:** Always use the lazy initializer pattern `useState(() => loadData())` for state requiring synchronous localStorage reads or expensive functions on mount.
