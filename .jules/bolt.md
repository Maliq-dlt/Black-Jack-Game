## 2024-05-18 - Optimize combo detection for blackjack hands
**Learning:** For small arrays (N < 20, e.g., blackjack hands), manual nested loops (O(N^2)) drastically outperform higher-order array methods (`map`, `some`, `forEach`, `every`) and object allocations. The overhead of object instantiation and closure creation dominates execution time. Also, using `Array.find()` on static configuration arrays within frequently evaluated loops causes unnecessary O(N) scans.
**Action:** Replace inefficient higher-order array methods with manual nested loops or pre-allocated arrays to eliminate redundant allocations and closure overhead for small array sizes, but retain native `.sort()` for code readability. Additionally, precompute Maps for O(1) retrieval (e.g., `COMBO_BONUSES_MAP`) instead of iterating over base arrays.
