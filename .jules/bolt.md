## 2025-02-27 - Performance pattern: Avoiding O(N*M) higher-order functions for small arrays
**Learning:** For small arrays (N < 20, e.g., blackjack hands), manual nested loops (O(N^2)) outperform `Set` (O(N)) and higher-order array methods (`map`, `some`, `indexOf`) because the overhead of object instantiation and closure creation dominates execution time. Benchmarking showed ~64%-90% faster execution for operations like checking pairs and three of a kind on standard 5-card hands when avoiding `.map().some()`.
**Action:** When evaluating hands or doing intense matching logic on small fixed-size arrays, prefer standard `for` loops instead of modern chained array methods (`map`, `filter`, `some`) to avoid redundant memory allocations and garbage collection overhead in tight loops.
