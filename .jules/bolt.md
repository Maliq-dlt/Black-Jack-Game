## 2026-07-05 - Optimize React state initialization from localStorage
**Learning:** In the `App.tsx` component, the `loadMeta`, `loadSettings`, and `loadStats` functions read from `localStorage` synchronously. Because these functions were defined inside the component and called during state initialization without lazy initialization (`useState(() => ...)`), they were unnecessarily redefining and causing potential performance bottlenecks during re-renders, as standard `useState(initialState)` evaluates the argument on every render, even though the result is only used on the first render.
**Action:** Move persistence loading functions (`loadMeta`, `loadSettings`, `loadStats`) outside the component body to prevent recreation. Use React's lazy state initialization (`useState(() => ...)` instead of `useState(value)`) so that `localStorage` is only accessed synchronously once on the initial mount, avoiding unnecessary reads on subsequent re-renders.
