## 2024-06-25 - High-Frequency Array Operations on Small Data Sets
**Learning:** For small arrays (N < 20, e.g., blackjack hands), manual nested loops (O(N^2)) significantly outperform object dictionaries, Map objects, and higher-order array methods (`map`, `some`, `forEach`). The overhead of object instantiation and closure creation dominates execution time. In profiling, `hasThreeOfAKind` execution time dropped from ~650ms to ~15ms per 1M iterations by replacing a dictionary-based count with a nested array loop.
**Action:** When working on frequently executed core loop functions that process small arrays, avoid creating objects, dictionaries, Maps, or chaining higher-order array methods. Implement manual nested `for` loops instead to optimize memory usage and CPU cycles.
